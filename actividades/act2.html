    #include <stdio.h>
    int main() 
    {
        int edad;
        printf("¿Cuántos años tienes? ");
        scanf("%d", &edad);


        if (edad >= 18) {
            printf("Eres mayor de edad.\n");
        } else {
            printf("Eres menor de edad.\n");
        }

        return 0;
    }


        Comenzamos con la primera línea #include <stdio.h>,
        en dónde se designa la biblioteca a utilizar para el funcionamiento correcto del código, es decir, una biblioteca es 
        aquel paquete de funciones que se deben incluir previo a la compilación y prueba del código.
        Por lo que si no se establecen, no se reconocerán las funciones utilizadas que pertenezcan a dichas bibliotecas.
    

        La segunda línea int main(),
        Establece que al ser una función, va a tener el estado de principal, por el main(), en dónde se englobará la mayor parte del código
        dicha función va a devolver un valor entero, designado por el int, y los () que al devolver un entero, es decir, 0, los parentesis 
        devvolverán un void, de vacío o una acción.
    

        En cuanto a la tercera línea int edad, se establecen las variables que se usarán en el código, es decir, una variable
        int de integer, llamada edad.
    


        Aquí se va a mandar a la terminal la acción de printf("¿Cuántos años tienes?");, ya que eso es lo que hace, imprimir una cadena de texto o
        valor numérico, etc.
        Como ocurre en la línea 4, 7 y 9. Algo importante es que en la 7 y 9, se utilizan saltos de línea \n
    

        En la quinta línea, tenemos una mascara con scanf scanf("%d", &edad);
        %d la cual recibe un número entero, de la variable. 
        Y finalmente &edad que por medio del & obtiene la dirección de memoria de la variable designada, es decir, memoria.
    

        Aquí tenemos un condicional if (edad >= 18), que en este caso de acuerdo con la variable edad, veremos 
        si cumple con el >=18 y else, que es la alternativa si no cumple con el condicional.
    

        Aquí devuelve 0 return 0; si todo salió bien.
